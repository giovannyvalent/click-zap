# TELAS E UX

## Marketing `/`

Objetivo:
- vender ClickZap;
- Google orgânico/inbound;
- CTA para cadastro.

Mensagem principal:
> Seu catálogo. Seu carrinho. Seu WhatsApp.

Seções:
- hero;
- como funciona;
- principais recursos;
- exemplos;
- para quem é;
- planos;
- FAQ;
- CTA final.

## Onboarding

Passo 1:
- nome do negócio;
- slug;
- WhatsApp.

Passo 2:
- entrega/retirada;
- tipo de frete.

Passo 3:
- primeira categoria.

Passo 4:
- primeiro produto.

Passo 5:
- publicar e copiar link.

Permitir pular categoria/produto e completar depois, mas não publicar até os requisitos mínimos.
